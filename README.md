Music Universe is a web project I created that transforms Spotify playlists into a 3D musical galaxy. Each song becomes a clickable planet; the song's genre determines which galaxy it belongs to, while metrics such as play count, energy level, and release year influence the planet's size, color, and position. Users can navigate between galaxies much like exploring outer space and click on any planet to view song details, open the track on Spotify, or use the official Spotify player to listen to an available audio preview.
The project utilizes Three.js to render the galaxies, nebulae, particles, and planet models, and the web page itself runs entirely without a backend.



Once on the page, you can left-click and drag to pan your position in the universe, right-click and drag to rotate the view, and use the scroll wheel to zoom. The galaxy directory on the left can be hidden or reopened; clicking a genre name within it automatically moves the view to the corresponding galaxy.
The search bar at the top is useful when dealing with a large number of songs; you can search by song title, artist, album, or genre. Clicking a search result takes you directly to the corresponding planet and opens the song details. Clicking the song tag on a planet achieves the same result, while the close button in the top-right corner of the details card returns you to the previous view.



What I appreciate most is that it isn't just an ordinary playlist, but a musical space that can be navigated and explored. The combination of song search, the galaxy directory, and automatic camera focusing means that even with a large number of tracks, you don't have to painstakingly hunt for a specific one amidst a cluster of planets. When importing a large volume of songs, the app automatically expands the layout outward to prevent overcrowding at the center; furthermore, if you want to switch to a different set of music, you can save the current arrangement as a new "universe" while preserving the previous one. This process transforms your listening history into a personal map that you can revisit time and again.

The page's "Import Playlist" feature supports CSV files exported via Exportify as well as JSON data returned by the Spotify Web API. When using Exportify, you can export the desired playlist after logging into Spotify and then drag the downloaded `.csv` file into the import window; alternatively, if uploading a file is inconvenient, you can simply paste the full CSV content. If a Spotify track link is missing, a search link is generated based on the song title and artist.

The "Open on Spotify" button on the song detail card opens the specific song page; however, if the imported data lacks a valid Spotify track ID, it opens the Spotify search results instead. The 30-second playback function utilizes the official Spotify iFrame player.
Users can talk with chatbots in "Community", each bot has its own favorite music type.



During development, I used Gemini and Codex to help build the framework and discuss layout strategies for Three.js; they also helped me quickly organize my approach to implementing CSV imports, Spotify playback, and search functionality. I extensively modified the initial drafts generated by Codex, primarily by integrating a 3D library and community features, as well as connecting to the Spotify API.
